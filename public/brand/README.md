# Brand assets

Place the official GraphInk Media logo here as:

    public/brand/graphink-logo.jpeg

`.svg`, `.png` or `.webp` also work (checked in that order: svg → png → webp → jpeg → jpg).
The site reads the file's real dimensions and renders it unchanged — no redraw,
recolor or cropping. Until the file exists, the brand name is shown as text.

Also recommended once the logo is available: replace `src/app/icon.svg`
(the favicon, currently a neutral registration mark) with a square version of the logo.
